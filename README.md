# 📸 AK CLICKS
### Photography Booking & Story Shop Platform

AK CLICKS is a full-stack web application developed using **Python Flask**, **HTML**, **CSS**, **JavaScript**, and **SQLite**. It combines a professional photography booking platform with an integrated online bookstore called **The Story Shop**.

The application allows customers to browse photography services, book sessions, purchase books, manage their accounts, and download payment receipts. It also provides an admin dashboard for managing bookings, orders, inventory, and customer activities.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/Adhithyakumar2010/AK_CLICKS.git
```

## Move into the Project Folder

```bash
cd AK_CLICKS
```

## Install Required Packages

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
