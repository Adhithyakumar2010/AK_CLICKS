# 📸 Integrated Photography Booking & 📚 Story Store Platform Using Flask Framework

A full-stack web application developed using **Python Flask** that combines two independent systems into a single platform:

- 📸 Photography Booking System
- 📚 Story Store (Online Bookstore)

Both modules operate independently with separate customer authentication, dedicated dashboards, independent admin panels, and isolated workflows while sharing the same Flask application.

---

# 📖 Project Overview

The **Integrated Photography Booking & Story Store Platform** is designed to provide two complete web-based solutions within a single application.

The **Photography Booking System** allows customers to browse photography services, schedule bookings, make secure online payments, and manage bookings through a personalized dashboard.

The **Story Store** provides a modern e-commerce platform where users can browse books, search by categories, manage wishlists, purchase books, track deliveries, leave reviews, receive personalized recommendations, and manage their accounts.

The platform also includes independent administration panels for both modules, providing inventory management, analytics, customer management, reporting, notifications, security controls, and payment management.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Adhithyakumar2010/AK_CLICKS.git
```

Move into the project folder

```bash
cd AK_CLICKS
```

---

## Create Virtual Environment

Windows

```bash
python -m venv venv
```

Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

---

## Install Requirements

```bash
pip install -r requirements.txt
```

# ▶ Run the Application

